This site is the only product in scope (no adjacent platform). But within the site itself, sequencing dependencies exist:

```
P0: Fix typo + hide bad links + wire domain
         ↓
P1: Write guides (content) → MailerLite automations → lead magnet funnel live
         ↓ parallel track
P1: Install Plausible → /thank-you page → measure funnel
         ↓
P1: Migrate PDFs to Lemon Squeezy (unblocked when 5 guides/worksheets exist)
         ↓
P2: Launch Tier 3 (60-min call) → service ladder complete through Tier 3
         ↓
P2: SEO content → organic traffic → email list growth → Tier 4 viable
         ↓
P3: Tier 4 nav package → group workshop → Tier 5 sliding-scale
```

**B2B flywheel sequencing** (from discovery strategy):

```
SBIRT/intake coordinator outreach (external, start now)
         ↓ referrals generate calls
calls establish credibility
         ↓ 6–12 months
B2B consulting conversation opens naturally
         ↓
B2B guide (P2) + B2B intake form (P2) + case studies (P3)
accelerate the close
```

The B2B flywheel does not require any code changes — it runs in parallel with all technical work and should start immediately.
