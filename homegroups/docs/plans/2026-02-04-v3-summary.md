2. **Referral Rewards** - 1 month free per conversion
3. **Referral Dashboard** - Track referrals and status
4. **Leaderboard** - Top referrers recognition

### Key Implementation Points

**Referral Code System:**
```typescript
interface ReferralCode {
  code: string;          // e.g., "JOHN2024"
  creatorId: string;     // Admin who created
  creatorGroupId: string;
  createdAt: Date;
  uses: number;
  maxUses?: number;
  expiresAt?: Date;
}

interface Referral {
  id: string;
  referralCode: string;
  referrerId: string;
  referredUserId: string;
  referredGroupId: string;
  status: 'pending' | 'converted' | 'expired';
  convertedAt?: Date;
  rewardApplied: boolean;
}
```
