- **Feature completeness is high (+):** All six core requirement areas (meetings, groups, comms, treasury, governance, monetization) implemented and verified, plus V4 scale work done (QR check-in, trial/renewal FCM, treasury report gate). Backend well-tested (40 Jest suites + rules tests).

Launch gated on un-started P0 ops: claim-and-pay E2E never run, no store submission (every download CTA 404s), Auth domains, email sender, RATS_API_KEY binding, Stripe default-price gate (−12). Mobile unit coverage well below 80% + flagged CRITICAL `useSelector` crash (UNVERIFIED) (−4).
- **Net: code is launch-grade; launch is blocked by operational + abuse-hardening tasks, not missing features.**

- **Feature breadth is strong (+):** Resident/house management, GPS verification, rent payments (2% Connect fee), subscription lifecycle, offline queue, paywall, Oxford data layer all implemented and verified; strong test footprint (291 mobile + 34 functions + 100 web specs).
- **Deductions:** Two documented feature claims do not exist — e-signature and Oxford-CRUD-as-CFs (−12). Confirmed weak rules + security self-score 68/100 (−8). Eight human-only P0 store tasks incl. rotate+purge 3 leaked service-account keys, delete E2E prod data, HIPAA BAA decision, ToS/Privacy hosting, IAP-vs-direct decision (−8). 40 npm vulns + EOL stack (−4).
- **Net: more feature surface than homegroups, but a fatal build break + leaked-secrets history rewrite + two phantom features put it materially further from launch.**

## Cross-product critical path

**Single highest-leverage next action: fix the one-line unterminated import in `regroup/functions/src/callable/homegroups.ts:6` (`import exa from "exa-`).**

- **S-effort fix, Critical blast radius.** While it stands, regroup's functions cannot `tsc`, cannot deploy, and the functions Jest suite cannot compile — no other regroup backend work can be validated or shipped. It silently invalidates regroup's 34-suite functions test footprint.
- **It sits on a cross-product seam.** The broken file (`homegroups.ts`) is the regroup→RecoveryConnect bridge (`getResidentMeetingAttendance` → homegroups `getMeetingAttendance` via `RATS_API_KEY`) — the same seam as the documented isolation violation (H11), which depends on homegroups binding `RATS_API_KEY` (I-4). Fixing the build makes the bridge testable.
- **Every regroup launch gate (#2 secrets, #5 HIPAA, #10 billing) requires a deployable build to verify.** Unblocking the compiler is the prerequisite that makes the rest of regroup's roadmap executable.

Homegroups' highest-leverage action runs in parallel and is independent: **set the Stripe default price on the intergroup A/B products (#3)** — also S-effort, Critical severity, because without it every intergroup/treatment-center checkout throws at runtime, silently killing the B2B revenue path.
